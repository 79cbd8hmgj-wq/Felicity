## Source grading
- **A:** Direct measurement / identifiable OEM documentation / VIN-matched repair procedure.
- **B:** Established technical publication or corroborated original brochure.
- **C:** Owner observations / shop assessment pending diagnosis.
- **D:** Forum anecdotes / assumptions / unverified interchange.

Every component or repair claim should preserve a source pointer, applicable year/market/trim, and level of confidence. Public repo material should not expose private vehicle or ownership identifiers.
