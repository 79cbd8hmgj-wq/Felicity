## Independently checked against primary manufacturer documentation

### A245E / EPC shift-kit compatibility

**TransGo SK A246** manufacturer listing explicitly covers **2003–2008 Corolla 1.8L A245 with EPC pressure-control solenoid**; this is a plausible 2004 A245E engineering upgrade, **conditional on confirming this car's installed valve-body/EPC configuration**. It is a valve-body repair kit, not evidence of a universally stronger automatic or greater torque capacity.

**TransGo A245-HD2** manufacturer states **1993–2002 A245E without EPC**. It should remain **excluded** from this June-2003 Corolla's upgrade shortlist, not be advertised as compatible merely because the transmission family is A245E.

Primary sources:
- https://transgo.com/product-details/toyota-a246e-shift-kit/
- https://transgo.com/product-details/toyota-a245e-reprogramming-kit/
- https://res.cloudinary.com/transgo/wbiss/sk/SKA246.pdf (manufacturer installation instructions)

**Engineering note:** Installation document notes hydraulic/check-ball variations across model years. Confirmation must involve the exact control hardware, not generic fitment alone. This is a proposed internal transmission modification, not a required service item.

### Historic TRD supercharger for 2004 Corolla automatic

The period TRD installation packet SC-COR-002-A / SC-MAT-002-A lists **00602-17620-114 for 2004 Corolla automatic** and requires a matched TRD ECU kit. It explicitly warns against aftermarket cold-air intake systems, because original air-filter housing and MAF arrangement are calibration-critical.

Evidence: https://www.scribd.com/document/57251082/TRD-SC-Install-1

**Engineering note:** The subject car has a photographed open-cone aftermarket intake. Therefore this period TRD package must not be classified as a drop-in upgrade with the current induction configuration. The historical packet establishes an original option, not current kit availability, emissions legality, ECU usability or a dyno gain on this car.
